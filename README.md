## 📱 소개

> PIUM은 사용자가 특정 위치에 3D 꽃 오브젝트와 사진, 텍스트 기록을 남길 수 있는 공간 기반의 아카이빙 앱입니다.
사용자는 방문한 장소에 당시의 추억을 기록하는 오브젝트를 남기고 이를 AR뷰를 통해 되돌아 볼 수 있습니다.
공간과 기록이 함께하는 경험을 제공합니다. 

[🔗 앱스토어/웹 링크](https://example.com)

## 🛠 기술 스택

- Swift 5.9 / SwiftUI / UIKit
- Xcode 15.0
- 아키텍처: MVVM
- 프레임워크: MapKit, ARKit, RealityKit
- 테스트: XCTest
- 기타 도구: Figma, Notion, GitHub Projects
- CI/CD: 미정
- 배포: 미정


## 🌟 주요 기능

- ✅ 장소 기반 3D 오브젝트 기록 남기기 
    사용자는 현재 위치를 기반으로 3D 꽃 오브젝트와 사진, 텍스트 기록을 남길 수 있습니다.
    같은 장소에 다시 방문 했을시 여전히 남겨져 있는 나의 꽃 오브젝트를 볼 수 있습니다. 
- ✅ 나의 기록 다시 보기
    내가 남긴 기록을 리스트 뷰, 지도 뷰로 다시 볼 수 있습니다.

## ✅ 테스트 방법

1. 이 저장소를 클론합니다.

    ```bash
    git clone https://github.com/DeveloperAcademy-POSTECH/2025-C4-M6-OMR.git
    ```

2. `Xcode`로 `.xcodeproj` 또는 `.xcworkspace` 열기
3. 시뮬레이터 환경 설정: iPhone 15 / iOS 17
4. `Cmd + R`로 실행 / `Cmd + U`로 테스트 실행
